This game is developed under 48 hours in APPS GameJam
itch.io: https://omerkeskin.itch.io/cubinary

**The Game**
Solve the grid, serve the food. Decode 3x3 patterns to launch ingredients across the screen. It’s a rhythmic blend of sharp logic and fast reflexes where every completed recipe is a victory for the flow state.

**Tactile Feedback:** Break, create, laser, paint and refresh the blocks to match ingredient patterns
**Timer Logic:** Finish the dish before the clock runs out.
**Portrait Perfection:** Optimized for a seamless 9:16 mobile experience
